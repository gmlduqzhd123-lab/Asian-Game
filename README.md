# 🏆 엽쌤의 아시안게임 체육 수업

아시안게임 종목을 교실·강당에서 할 수 있는 **리드업 게임**으로 바꾼 체육 수업 웹앱입니다.
`index.html` 파일 하나로 동작하며, 파일을 저장해서 열면 **인터넷이 없어도** 쓸 수 있습니다.

## 수업 흐름 (상단 탭 ①~⑥)
1. 🤸 **준비운동**: 공통 동작과 종목별 동작을 20초씩 자동으로 넘기고 소리로 알려 줍니다.
2. 🎬 **미션**: 아시안게임 영상을 누르면 앱 안에서 바로 재생됩니다. 규칙 카드도 보여 줍니다. 🌱쉬움(그림 카드) / ⭐기본 / 🔥도전 난이도, 준비물 체크리스트, 안전 수칙이 들어 있습니다.
3. 🎲 **팀·역할**: 반별 명단으로 팀을 나누고, 종목별 역할 인원에 맞춰 역할을 배정합니다. 라운드마다 역할을 교대할 수 있습니다.
4. 🎯 **경기**: 2~6팀 점수판(+1/+2/+3, 되돌리기, 숫자를 눌러 직접 입력)과 시간 경기용 레이스 시계(도착 기록, 벌칙 초)를 제공합니다. 페어플레이·응원 점수, 종목별 추천 타이머, 브레이킹용 🎧 DJ 모드도 있습니다.
5. 🏅 **시상**: 시상대 애니메이션, 페어플레이상·응원상, 반별 **종합 메달 순위표**(금→은→동)를 보여 줍니다.
6. 😀 **성찰**: 이모지 투표와 성찰 질문으로 수업을 마무리합니다.
- ❓ **OX 퀴즈**: 아시안게임·스포츠 상식 31문제가 들어 있습니다.

## 선생님 도구
- **▶ 수업 시작**: 40·45·50분 수업 흐름 타이머입니다. 지금 할 단계에 초록 점이 표시됩니다.
- **🔍 종목 찾기**: 장소, 학년, 준비물 간단, 조용한 활동, 유형으로 종목을 거를 수 있습니다.
- **🖨️ 인쇄**: 수업 지도안과 학생 학습지를 인쇄합니다.
- **⚙️ 설정**: 팀 수와 팀 모양(색깔 팀, 청군·백군, 🌏 아시아 국가 국기+인사말), 효과음, 수업 시간을 정합니다. **✏️ 종목 편집**으로 코드 없이 규칙·역할·점수 방식·영상 주소를 고치거나 새 종목을 만들 수 있습니다. 백업과 종목 공유 파일도 여기서 만듭니다.
- **⛶ 전체화면**: 전자칠판에 띄울 때 씁니다.
- 경기 탭에서 키보드 숫자 **1~6**을 누르면 해당 팀 점수가 올라갑니다.

## 디자인
- 제목 글꼴은 동글동글한 **Jua**, 본문 글꼴은 깔끔한 **Pretendard**입니다. 인터넷이 없으면 컴퓨터 기본 글꼴로 보입니다.
- 밝은 크림색 배경에 파스텔 포인트 색을 쓰고, 버튼은 말랑한 입체 느낌으로 만들었습니다. 색은 `index.html` 맨 위 `:root`의 색 변수에서 한 번에 바꿀 수 있습니다.

## 유튜브 영상
- 종목마다 추천 영상이 들어 있고(`VIDEO_PICKS`), 누르면 앱 안 플레이어에서 바로 재생됩니다.
- 파일을 내려받아 컴퓨터에서 바로 연 경우(`file://`)에는 유튜브 정책상 앱 안 재생이 막혀서, 유튜브 새 창에서 바로 재생됩니다. GitHub Pages처럼 웹 주소로 열면 앱 안에서 재생됩니다.
- 영상이 삭제되었거나 퍼가기가 막힌 영상이면 플레이어 아래 **유튜브에서 바로 보기** 버튼을 누르세요. ⚙️ 설정 → ✏️ 종목 편집에서 `제목 | 유튜브 주소` 형식으로 영상을 바꿀 수 있습니다.

## 종목 내용 고치기
- 앱 안에서 고치려면 ⚙️ 설정 → ✏️ 종목 편집을 쓰세요. 고친 내용은 이 브라우저에 저장됩니다.
- 코드에서 고치려면 `index.html`의 `📚 종목 데이터` 부분(`DEFAULT_EVENTS`)을 수정하세요.

## 오프라인용 CSS 다시 만들기
새 Tailwind 클래스를 추가했다면 아래 명령으로 내장 CSS를 다시 만들어 주세요. 인터넷이 될 때는 CDN이 자동으로 적용되므로 이 작업을 하지 않아도 화면은 정상입니다.

```bash
npm install
npm run build:css
```
