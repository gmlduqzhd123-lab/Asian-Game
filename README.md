# 🏆 엽쌤의 아시안게임 체육 수업

아시안게임 종목을 교실·강당에서 할 수 있는 **리드업 게임**으로 바꾼 체육 수업 웹앱입니다.
👉 **바로 쓰기:** https://gmlduqzhd123-lab.github.io/Asian-Game/

- 처음 열면 **🚀 빠른 시작**이 나와요: ① 종목 → ② 반 명단 → ③ 팀만 고르면 수업이 시작됩니다.
- 한 번 접속하면 **인터넷이 끊겨도** 열리고, 휴대폰·태블릿은 **홈 화면에 추가**해서 앱처럼 쓸 수 있어요.

## 수업 흐름 (상단 탭 1~6)
1. 🤸 **준비운동**: 공통 동작과 종목별 동작을 10·20·30초씩 자동으로 넘겨요. 이모지가 동작처럼 움직이고, 목소리로 동작 이름을 알려 줘요. 따라 하기 영상도 있어요.
2. 🎬 **미션**: 아시안게임 영상을 누르면 앱 안에서 바로 재생돼요. 규칙은 늘 보이고, 🌱쉬움(그림 카드) / ⭐기본 / 🔥도전 난이도를 고를 수 있어요.
   - **📽️ 크게 보기**: 규칙을 한 장씩 아주 크게 보여 주는 슬라이드 (리모컨 ←/→)
   - **🔈 읽어 주기**: 규칙을 목소리로 읽어 줘요
   - **🌐 그림 카드 언어**: 한국어 · English · Tiếng Việt · 中文 (다문화 학생용)
3. 🎲 **팀·역할**: 반별 명단 → **출석 체크**(결석생 빼기) → 팀·역할 섞기 → 라운드마다 역할 교대. 두 친구 이름을 차례로 누르면 **자리를 맞바꿀 수** 있어요.
4. 🎯 **경기**: 2~6팀 점수판(색 + 모양 ●▲■★◆♥로 구분), 시간 경기용 레이스 시계, 페어플레이·응원 점수, 추천 타이머(10초 남았을 때 음성 안내).
   - 🧰 도구: **🗓️ 리그 대진표**(순위대로 시상), **📋 개인 기록·평가**(엑셀 CSV로 받기), **🎧 DJ 모드**, **🎮 리모컨 점수**
5. 🏅 **시상**: 시상대 애니메이션, 페어플레이상·응원상, 반별 종합 메달 순위(금→은→동).
6. 😀 **성찰**: 이모지 투표와 성찰 질문(읽어 주기).
- ❓ **OX 퀴즈**: 전체 문제(아시안게임 상식 + 종목별) 또는 **이 종목 문제**만, 퀴즈 팀 점수.

## 선생님 도구
- **👀 학생 화면**: 빔프로젝터·전자칠판에 띄울 때 선생님용 버튼을 숨기고 글씨를 키워요.
- **☰ 메뉴**: 빠른 시작, 수업 흐름 타이머, 글씨 크기(보통/크게/아주 크게), 효과음, 음성 안내, 전체화면, 지도안·학습지 인쇄, 개인 기록, 앱 설치, 도움말, 설정.
- **⚙️ 설정**: 팀(색깔 팀 · 청군·백군 · 🌏 아시아 국가), 화면·소리, **보이는 종목**(추천 8개만 보기), 종목 편집(코드 없이), 백업·개인정보.
- **🔒 개인정보**: 이름 대신 **번호 명단**을 쓸 수 있고, 수업 뒤 **🧹 수업 끝 정리**로 공용 컴퓨터에서 학생 이름을 지울 수 있어요. 모든 기록은 서버로 보내지 않고 이 브라우저에만 저장돼요.

## ⌨️ 키보드 · 발표용 리모컨
| 키 | 하는 일 |
|---|---|
| → / PageDown | 다음 (준비운동: 다음 동작 · 퀴즈: 정답 공개/다음 문제 · 그 밖: 다음 단계) |
| ← / PageUp | 이전 단계 |
| 1 ~ 6 | 경기 탭에서 해당 팀 점수 +1 (시간 경기는 도착 기록) |
| B 또는 . | 경기 탭에서 타이머 시작/정지 |
| 🎮 리모컨 점수 켜짐 | PageUp = 1팀 점수, PageDown = 2팀 점수 |
| Esc | 열린 창 닫기 |

## 접근성
- 글씨와 버튼 색은 배경과 **대비 4.5:1 이상**(웹 접근성 기준 AA)이 되도록 골랐어요. 팀 색이 밝으면 자동으로 조금 진하게 바꿔요.
- 모든 버튼은 손가락으로 누르기 좋게 **44px 이상**이고, 키보드로 움직이면 선택된 곳이 굵은 테두리로 보여요.
- 브라우저 기본 팝업 대신 앱 안 확인 창을 써서 전체화면·태블릿에서도 막히지 않아요.
- 화면 움직임 줄이기 설정(prefers-reduced-motion)을 켜면 애니메이션이 멈춰요.

## 유튜브 영상
- 종목마다 추천 영상이 들어 있고(`VIDEO_PICKS`), 누르면 앱 안 플레이어에서 바로 재생됩니다.
- 파일을 내려받아 컴퓨터에서 바로 연 경우(`file://`)에는 유튜브 정책상 앱 안 재생이 막혀서, 유튜브 새 창에서 재생됩니다.
- 영상이 안 나오면 플레이어 아래 **유튜브에서 바로 보기**를 누르세요. ⚙️ 설정 → ✏️ 종목 편집에서 `제목 | 유튜브 주소` 형식으로 바꿀 수 있어요.

## 내용 고치기
- 앱 안: ⚙️ 설정 → ✏️ 종목 편집 (이 브라우저에 저장, 📤 내보내기로 공유)
- 코드: `index.html`의 `📚 종목 데이터`(`DEFAULT_EVENTS`)와 `📚 추가 데이터`(`RECOMMENDED`, `QUIZ_EVENT`, `EASY_I18N`, `WARMUP_DEMOS`)

## 개발 메모
- 화면 디자인은 Tailwind CSS를 `index.html` 안에 넣어 쓰고 있어요(인터넷 없이 동작). **새 Tailwind 클래스를 추가했다면 꼭 아래 명령을 실행**해 주세요.
  ```bash
  npm install
  npm run build:css
  ```
- 오프라인 지원은 `sw.js`(서비스 워커)가 맡아요. 앱을 고쳐 배포할 때 `sw.js`의 `CACHE` 이름 숫자를 올리면 학생 기기에도 새 버전이 확실히 적용돼요. (인터넷이 되면 앱 화면은 항상 최신 버전을 먼저 가져와요.)
- 파일 구성: `index.html`(앱 전체) · `sw.js` · `manifest.webmanifest` · `icons/` · `og-image.jpg` · `scripts/build-css.mjs`
